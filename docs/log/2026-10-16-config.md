# Config out of the code (16 October 2026)

Kenil, before Doc: "I want all static/config data maintained cleanly and isolated to the code.
this includes prompts, models, settings, every static thing.. So that i can update those
easily without having to update the code files." Agreed: TOML for models and limits, Markdown
for prompts and briefs; prompts reload on edit, models and limits at start; the window's words
stay in its components; this before Doc.

## Measured first

18 model-facing texts as Python constants in 11 files; the model chosen in four places by
different means (`claude_cli.DEFAULT_MODEL`, `judge.DEFAULT_MODEL`, two environment variables
read in six spots, Codex's effort map); 48 named judgements and timings across 12 files; 17
environment variables read where used. Already outside the code, and right: the connectors,
the journeys, `launch.json`, the pins, and everything the person shapes (their instructions,
an agent's brief and name, preferences, looks), which lives in the world.

## What was built

- **`core/alpha/config/`**: `prompts/*.md` (18 files, moved verbatim; `{{name}}` placeholders),
  `briefs/watson.md`, `models.toml` (turn, judge, independent, refile, trial; the ChatGPT
  route's alias→effort), `limits.toml` (every judgement in 14 groups, each with its why),
  `README.md` (every file and who reads it).
- **`core/alpha/config.py`**: `settings` (typed, frozen dataclasses built from `limits.toml`
  at import; a wrong, missing or unknown key fails the start naming it), `model_for(role)` with
  the two environment overrides, `chatgpt_effort(alias)`, `prompt(name, **fill)` and
  `brief(kind)` read on use and cached by the file's modification time (an edit reaches the
  next turn, no restart), `prompt_names()`, `brief_names()`.
- **Threaded through** 31 modules: each prompt is now a `config.prompt(...)` call where it is
  used; each constant binds its name from the settings (`SILENCE_S = settings.runs.silence_s`),
  so the code reads as before and tests still patch the names; the model choices are
  `config.model_for("turn" | "judge" | "independent" | "refile" | "trial")`; the one schedule
  floor and the window's allowed origin come from the settings too.
- **Tests** (`test_config.py`): the limits load typed and every group is read by name; a wrong,
  missing or unknown key fails plainly; every prompt file is used and every prompt used exists;
  placeholders are filled and an unfilled one is a mistake; an edit reaches the next call; the
  models table and the environment's say, on both routes.
- **Docs:** CONTRIBUTING's new "Config" section, README's layout, CLAUDE.md's rule.

What did not move, on purpose: the walls and checks (the gates, the write list, the parsers),
the schema, the words the person reads, the enumerations, discovery lists (where Node or Chrome
may be), and the window's labels. The why-comments above the constants in the code were kept
where they carry history (dates, measurements); `limits.toml` carries the short why.

## Proven

281 core tests, ruff and mypy clean; no behaviour changed, so the desktop is untouched. Two
journeys with the real model after the move, on a copy of Kenil's world, prove a live turn
reads its instructions from the files: `question_card` (`docs/journeys/2026-10-16-1214.md`)
and `memory_follow_up`, two real turns with Watson's pass after each
(`docs/journeys/2026-10-16-1215.md`), both passed.
