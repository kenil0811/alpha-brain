# Columbo, the checker (16 October 2026)

Q47 built on Q50's substrate, proposed in writing and agreed ("ok to all, lets begin" to seven
points: answers checked when they carry numbers, by shape; one check per part on its first filled
row and again after a repair, a part's difference asking the person; outward numbers checked
before the yes, shown on the card, never blocking; the person asked once when sources still
disagree after Alpha's correction turn, their answer binding; the ✓ / ≠ marks and the footer
count; the cat for now; the run succeeded when both ways answered, whatever they found).

## Measured first

The second opinion (`runtime/check.py`, since 2 Oct) had checked 18 answers in Kenil's world: 13
agreed, 2 differed (the shake's 160 kcal against the label's 215 among them), the rest gave no
verdict. It ran only after a turn that wrote worked-out values, one way (an independent answer
with web search), as a thread started behind the turn (`Turns.check`) with nothing around it:
no run row, no memory of which sources it had met, no mark on what it had checked, nothing for
the values a workflow's parts fill, nothing for an answer given only in words, and nothing for
the numbers in an outward card. `parts.run_part` already journaled a `did` per row filled with
the part, the record and the values, so a part's first filled row was there to find.

## What was built

- **`runtime/agents/columbo.py`** replaces `runtime/check.py` (the kind registered with its
  `look`, `run` and a `mention` of its own; the cat). `check_turn` is the old `check` made two
  ways: the outside way as before (the sentence answered again by the same model with web
  search and nothing of Alpha's, judged by a small run; `check_judge.md` now returns each
  difference as an object: what, Alpha's value, the independent one, the source) and the world
  way (`columbo_world.md`: a judging run given what Alpha held when it answered, read from the
  context kept with the turn, the MATCHES FOR THIS SENTENCE and WHO THE SENTENCE NAMES sections
  through `prepack.section_of`, now shared with the journey suite's judge, and the rows the
  turn wrote as they are; a world with nothing to say agrees without a model call). The
  `checked` entry carries both verdicts under Columbo's name; the run's verdict is succeeded
  when both ways answered, partial when one gave no answer, failed when nothing could be
  checked.
- **Triage by shape** (`look`): Alpha's replies to the person since Columbo's cursor that wrote
  worked-out values (`worth_checking`, as before) or carry a number the person will rely on
  (`carries_numbers`: a measurement with its unit, money, a percentage; a bare count, a date or
  a year is left alone, being the person's own); a part's first filled row with a number
  (`part_checked` says whether it was checked since its last repair, a `changed` of Doc's with
  `data.repair`); a `proposed` outward card whose payload carries numbers. Alpha's own turns (a
  correction, a repair) are never checked again, and a reply checked once is not checked twice.
- **Columbo never fixes.** A difference on an answer goes to Alpha as the correction turn it
  always was (`repair_prompt`, now with both ways' differences). After it, the row is read
  again: corrected to the source's value, the mark says it agrees now; still Alpha's own value,
  the person is asked once (`ask_person`: "Kcal of FGS shake: Alpha has 160, ocado.com says
  215. Which should Alpha keep?", the two values as the card's options, asked once per field
  while one is open). Their pick is handled by code in the answer route (`columbo.decide`): a
  decision of theirs, binding, with the other value as the alternative; the value kept on the
  row as their own edit when it differs (a number field takes the number out of the judge's
  words); the mark agreeing with what they chose; a note on Columbo's page saying whose side
  they took; no model turn. An answer that is neither value is a message like any other.
- **Parts** (`check_part`): the values a part filled on the row, looked up again outside
  (`columbo_values.md`) and judged against the rows the part filled before (`[columbo]
  sibling_rows` in `limits.toml`: enough to see a part giving every row the same number); no
  agent owns a part's values, so a difference asks the person straight away; each checked field
  carries the mark in its origin.
- **Outward cards** (`check_action`): the payload's numbers against the person's world (the
  proposing turn's kept context and rows, the rows matching the words) and outside for facts;
  Columbo's line kept on the action (`actions.checked`, a new column) and shown on the card as
  "Columbo: …"; the card's buttons are as they were, nothing waits on it; a card decided before
  Columbo looked is left alone.
- **The mark:** `Collections.mark_checked` writes `_provenance.checked` (the row) or
  `fields[f].checked` (a part's field) without a revision or a version, since a mark is not a
  change; the window shows ✓ or ≠ beside the value (`cells.tsx`, numeric cells of rows Alpha
  wrote; the record page shows it beside the source instead), "Checked by Columbo against
  <source>, <day>" on hover, and "n checked" in the table's footer beside "estimated".
- **`@Columbo check that`:** the first per-kind mention in code (`MENTIONS`, registered with
  the kind): the conversation's last answer is checked again now and the verdict said there in
  Columbo's name, with a run row (trigger `mention`); with nothing to check, the model answers
  as Columbo as for any agent.
- **Notes, written by code:** per source (its site) whether it agreed or differed; per kind of
  value what Alpha had against what the independent answer or the world had, whether Alpha
  corrected it, and whose side the person took.
- **What the real runs taught, built in the same afternoon** (the hand checks below): the
  person's own earlier sentences in the conversation or the stream travel with the sentence
  to the independent answer (theirs, never Alpha's replies), so "it" and "the module" mean
  something; the world's judge is shown whole rows, a dozen of them and a count of the rest
  (`[columbo] rows_shown`), after a cut mid-row read as "not loaded", and its rules say that
  what it is not shown is not a difference; a difference's loose match to a row's number
  field is made only for a bare number, never a sentence with a 6 in it; and when the
  sentence holds nothing the outside can know (the person's own file, a judgement), the
  independent answer says `NOTHING TO LOOK UP` in fixed words and code skips the comparison
  (the small judge kept listing "what is 'it'?" as unstated whatever its rules said: a
  mechanism, not a prompt).
- **Each built-in kind says in its own words when it works and what a good run is**
  (`register(..., words=…)`; the agent page shows them in place of the schedule's and the
  generic words: Watson's and Doc's pages gain this too).
- **Gone:** `Turns.check` and the `checks` flag; the kick's `looks()` wakes Columbo after a
  turn as it wakes Watson. `alpha check <turn>` runs Columbo by hand (and makes the built-in
  rows first); the journey suite's `independent` check calls it.
- **Config:** `columbo_world.md`, `columbo_values.md`, `check_judge.md` (differences as
  objects; what is not a difference; the "nothing to look up" rule), `check_independent.md`
  (the fixed words), `briefs/columbo.md`, `[columbo] sibling_rows` and `rows_shown`.

**Journeys, with the real model on copies of Kenil's world:** `vague_tracker` passed
(`docs/journeys/2026-10-16-1347.md`). `branded_food` failed in the same run on Columbo's check

an assumption about the sentence, never a value Alpha did not mention); rerun, it passed:
"Checked against an independent answer and your world: both agree." (`2026-10-16-1352.md`, 56 s
for the two ways).

**Columbo by hand on a copy of Kenil's world**, the same turn four times (his "can you check
again if you can download and load it into the module", which wrote 32 Advisory rows from his
RestoPros files), each change made before the next run:
1. The world's judge called absences differences ("A/P aging not shown in records", "metrics not
   present") because the rows it was shown were cut mid-list, and a sentence of Alpha's holding
   a 6 was matched to rows whose number field held 6: two rows wrongly marked ≠. Whole rows and
   a count of the rest; absence is not a difference; a loose match only for a bare number.
2. The world agreed; 32 rows marked ✓. The outside's independent answer asked what "it" and

3. With the person's earlier sentences, the same questions still came back: nothing in the
