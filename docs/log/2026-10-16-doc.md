## What was built

- **`runtime/agents/doc.py`**: the kind (the bear), `diagnose` by the failure's shape (alpha:
  the hand or the core did not run; passing: the network; yours: a sign-in, a bot check; else
  know-how) and `diagnose_part` with the model where a part's traceback does not tell
  (`doc_diagnose.md`); `repair_reader` (called by the pipeline, a lock per thing so a second
  run that meets the same broken reader waits and takes the fix, the turn in the caller's thread
  under Doc's name with Doc's notes about the thing in front of it, "try 2" told what try 1
  did), `settle` after the caller's rerun (the "Doc fixed the reader X: <why>" line with what
  changed, or "couldn't fix"; Doc's run row, trigger `called`, `called_by` the run), `mark_held`
  when the thing's next real run succeeds (said once; the pipeline and acting call it),
  `repair_procedure` (acting's path, under Doc), `repair_part` (a walled session in the
  module's workspace with the module's hosts, committed as "Doc: <why>" by the model or by
  code, the row rerun, the module's other failed rows retried, once per cause: a second crash
  the same way is reported, recorded as Doc's decision), `report` (the Mac's and Alpha's own
  faults, in plain words, one line per cause naming the agents), `look` (parts' failures and
  agents' runs that failed the hand's way, since Doc's cursor) and `run`.
- **Versions and Undo:** `skill_versions` keeps the version before every `Skills.save` with who
  replaced it (the tools pass their actor); `Skills.versions`, `Skills.restore` (a new version,
  journaled as the person's); `POST /api/skills/{name}/restore/{version}`; the skill page's
  Versions with Restore; "Undo this repair" on a run line of Doc's that changed a skill (the
  agent page's lines now carry what Doc changed). Purge takes the versions with the skill.
- **Try again** records its trigger as `again`.
- **Config:** `doc_diagnose.md`, `repair_part.md` (and `repair_reader.md`, `repair_procedure.md`
  now Doc's), `briefs/doc.md`, `[doc] wait_s` in `limits.toml`.
- **The journey suite** has a `break_reader` step (a reader's script set to return nothing on
  the copy) and the journey `doc_repairs_a_reader`.
- The journal can be read by actor (`recent(actor=…)`), so an agent's page shows its lines
  wherever they landed; Watson's checkpoint transcript was being shown newest first (the
  journal's `recent` is newest last), fixed.
