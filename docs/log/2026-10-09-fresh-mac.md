# Alpha on another Mac (9 October 2026)

Kenil shared the app with a friend and it didn't work for him. Read before anything was
changed: the bundle held only the window (the Tauri binary and an icon); the core was launched
from the repository's uv environment at a path compiled into the binary, and the connectors
from the repository too, so on any other Mac the host stopped at "Alpha's core isn't
installed"; nothing Alpha needs (Python, Node, Playwright's Chromium, Claude Code) was
installed by Alpha; and the app is signed with a local certificate, not notarized, so macOS
refuses a downloaded copy until the person right-clicks › Open. Kenil's answers: no Apple
Developer account for now, right-click is fine; the friend's Mac is Apple silicon. Q34.

**A shipped Alpha carries its runtime** (`just ship`, `desktop/scripts/ship.sh`,
`desktop/src-tauri/ship.conf.json`). The script assembles `desktop/src-tauri/runtime/`: uv's
standalone Python 3.13.9 pruned of Tk, tests and headers (36 MB); the core and its 85 locked
packages from `uv export --frozen --no-dev` installed into a plain `site-packages` (no venv,
so it moves); the official Node 24.21.0 binary from nodejs.org, checked against its published
checksum (Homebrew's Node links Homebrew's libraries and cannot travel); the connectors with
the browser driver and Playwright's own installer (`playwright` 1.62.0 added next to
`playwright-core`). A smoke test imports the core and loads Playwright from where they sit.
The release build takes the directory as its resources; the zip lands next to the app. 295 MB
on disk before the app itself.

**The host uses the runtime it carries** (`lib.rs`: `bundled_runtime`, `release_quarantine`,
`core_python`). When `Contents/Resources/runtime/python/bin/python3.13` exists the core runs
from it, with `PYTHONPATH` on the bundled packages, `ALPHA_NODE` on the bundled Node and
`ALPHA_CONNECTORS` on the bundled connectors; otherwise the repository's environment as before,
so Kenil's daily debug app is unchanged. A copy that arrived by download carries macOS's
quarantine mark on every file inside it, and right-click › Open answers for the app only: the
host clears the mark from its own runtime before launching the core (its own files, no
password), and says so in `host.log`.

**What the person must have is asked for inside the window** (`/api/browser`,
`/api/browser/install`, `connectors/browser.py`: `chromium_path`, `install`, `status`,
`progress_words`, `chrome_channel`; `BrowserRow` in Settings › Reads with; the first-run page).
Alpha's own browser is Playwright's Chromium, found by asking Playwright where it is; Install
runs Playwright's installer in the background (about 250 MB) and the row shows its progress in
words ("Downloading Chromium 151.0.7922.34… 40% of 160.4 MiB"); a failed install says why,
with Try again. The first-run page now reads "Set Alpha up to start" with two rows, the
account (as before) and the browser, and stays until both are there. Sign-in windows open in
the person's own Chrome when it is on the Mac, else in Alpha's Chromium (`chrome_channel`):
before, a Mac without Chrome could not sign in anywhere.

**Not done, by Kenil's choice:** notarization (needs an Apple Developer account). The friend's
copy is opened once with right-click › Open; the README says so.

**Checked, in a clean room on Kenil's Mac** (the shipped app copied to a scratch folder, every
file of its runtime marked with macOS's quarantine attribute as a download would be, launched
with an empty HOME and a PATH of only the system's). The host used the runtime it carries
("launching core: … runtime=…/Alpha.app/Contents/Resources/runtime"), cleared the mark from
all 7,882 files, and the core was ready in one second on a fresh world. Alpha's browser:
"Not installed" at first; Install ran Playwright's installer, whose words the row would show
("Downloading the browser… 90% of 178.7 MiB"), and Chromium and its headless shell landed in
the fresh HOME's cache; then "Installed". A public page read through the bundled Node and
that Chromium answered in 2.9 s ("Example Domain"). 223 core tests, 80 desktop, lint, mypy,
typecheck and `cargo check` clean. **Not proven:** Claude Code's Install and Sign in on a Mac
without them (Kenil's `claude` is on the system path, so the clean room found it; the Install
runs Anthropic's installer, unchanged since 2 Oct), and the friend's own first run, which is
the acceptance. The window's own Install was pressed in the clean-room app and the row went
from "Not installed" to "Installed · sign-in windows open in your Chrome". The bundle is 300 MB on disk, 96 MB zipped.

**Ran for real the same morning, in Kenil's world** (the agents slice, two commits earlier):
the Mac woke at 07:40 and the three daily agents ran with verdicts. The deal tracker:
succeeded, 15 of 15 sources, no model. The LinkedIn connections agent, a procedure since
1 Oct: its run converted it to steps and read LinkedIn in the same run, succeeded, 1 of 1,
4 min of model (the conversion), "2 new, 51 changed, 1 gone". The founding-engineer agent:
partial, 3 of 4 ("wellfound.com stops automated reading"), 3 repairs, 17 min of model.
