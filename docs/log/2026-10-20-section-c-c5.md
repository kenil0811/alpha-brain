## What the code did already

An agent's runs keep their own thread (kind `work`, owned by the agent). Since C3 the stream
reads Home and the person's own threads from before C, never an agent's. So nothing of a run
reached the stream except:
- its cards, which sit at the bottom wherever they arose (Q109);
- an `@Name` and its answer (Q107).

`tell_person` in a run journals `noticed` on the agent's own thread.

## Built

- **`agents.tell`**, a new column: the standing instruction that asks to be told of the
  agent's runs. The telling holds only while that instruction stands in ALPHA.md, so removing
  it there by hand stops it too.
- **`world_remember kind=instruction` with `about`** (an agent's id or name):
  - it keeps the instruction and sets the agent's `tell` to it, journaled "<agent>'s runs now
    come to the conversation";
  - an agent that isn't there is refused;
  - removing the instruction clears every `tell` that named it.

  The hand's words say when to pass `about` ("tell me whenever the tracker finds something").
  Code never reads the person's prose for it.
- **A run of a told agent** (`runner._tell`) puts its outcome in Home, as a `replied` line under
  the agent's own name ("<agent> reports" in the window):
  - a run's line, or "That run didn't work: …";
  - a run with nothing to say tells nothing;
  - any other run stays on its page and in Activity.
- **Morning** (an agent told by default) is not built, as the spec says ("when built").
