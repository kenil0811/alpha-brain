## 3. Strongest evidence on trust, explanation, review
1. Reviewing agent work fails: Grunde-McLaughlin et al. (Microsoft, arXiv 2602.16844, Feb 2026; three 12-person studies): verbose action traces "overwhelm users while hiding small but critical errors"; participants missed errors in 50–83% of tasks. A specification view (requirements checklist ✓ done / ? unknown / ✗ contradicted + explicit assumptions list, each linked to trace + annotated screenshot) was preferred and most accurate (77% vs 57–63%). Caveat: better navigation cut time ~10% but did not raise accuracy and increased false confidence (V).
2. Plans reduce bad actions; gates get rubber-stamped: Chen et al. (arXiv 2604.04918v2, Sep 2026; N=48): plan-based oversight cut problematic actions 76%, but of problematic actions reaching execution users blocked only 21%. Failures: gates too early/late; judging procedure not content; plan approval lowering scrutiny during execution. Users preferred per-action confirmation for low-stakes and plan + action + risk escalation for high-stakes (V).
3. Magentic-UI (arXiv 2507.22358): co-planning, co-tasking, action guards, multi-tasking, verification, long-term memory (V).
4. Proactivity timing/presence: Pu et al., CHI 2025 (arXiv 2502.18658, N=18): presence indicators (status bubble, visible cursor) cut disruption 4.61→3.78; interventions at task boundaries engaged 53%; idleness-triggered ones ineffective; lost ownership/understanding reported (V).
5. Amershi et al., Guidelines for Human-AI Interaction (CHI 2019): G1–2 what it can do and how well; G3 time services by context; G8 efficient dismissal; G9 efficient correction; G11 make clear why; G16 convey consequences; G17 global controls; G18 notify about changes (V).
6. NN/g State of UX 2026 (16 Jan 2026): trust a major design problem; transparency, control, consistency, support when it fails (V).
7. Yocco, Smashing (11 Feb 2026): Intent Preview (Proceed / Edit plan / Handle it myself), Autonomy Dial, Explainable Rationale ("Because you said X, I did Y"), Confidence Signal, Action Audit & Undo (time-limited), Escalation Pathway (practitioner) (V).
8. Calm Technology (Case): minimal attention, periphery, work even when it fails (V).
9. Provenance in product: Notion Mail shows matches before saving a rule; Cora briefs carry source attribution; Recall labels Close/Related (V).
10. macOS conventions (S): menu bar extras work when not frontmost; a panel floats above windows for supplementary controls. NSPanel recipe (fazm, 10 Apr 2026): .nonactivatingPanel, level .floating, .canJoinAllSpaces + .fullScreenAuxiliary, becomesKeyOnlyIfNeeded = true, never NSApp.activate on show. Spotlight in macOS Tahoe added actions and Quick Keys. "Always on top" belongs under Window ▸ Stay on Top.

## 4. Recommended information architecture
Premise: companion is primary; the window is where the person checks the agent. Every surface answers one of: what needs me? what does it hold? what did it do and why?
Rail (six): 1 Today (inbox + digest); 2 Areas (agent-designed topic modules by recency); 3 People (entities; documents/messages/events reached via entity and area pages, not a rail item); 4 Notes; 5 Journal (verbatim by day); 6 Activity (what the agent did, with undo) + quiet sub-pages "What runs on its own" and "What I can reach" as sentences. No Intelligence page; Home-with-onboarding becomes Today's empty state.
Today: lane (a) Needs you — outbound actions awaiting a yes, questions, drafts: card with the action in plain words, evidence, one-line "because…", Yes / Change / Not now (Zapier Needs action, Lindy draft-in-task, HEY decide-once for recurring sources); per-action approval for outbound; plan preview only for multi-step, still gate the consequential step. Lane (b) Digest — twice-daily sectioned cards (Cora: top actions / calendar / follow-ups; Gemini: Top of mind / FYI / Looking ahead) with thumbs and "why am I seeing this"; cards expire with the next digest unless kept (Pulse). No feed, no scroll history; badge only for Needs-you count.
Area page: 2–4 summary cards; derived views with inline edit (click-to-edit, save on blur/Enter, hover affordance; edits write straight back), record panel on the right; strips "What runs here" (automations as sentences with next-run) and "Recent changes" (agent edits, undoable). Saved lists = named filters.
Entity page: header with facts, each with provenance popover (source, date seen, valid-from/until) and inline "wrong?" correction; tabs Overview (recent/upcoming interactions, open items), Timeline (cross-source: emails, meetings, messages, pages read, turns mentioning them, agent actions), Related, Notes; optional keep-in-touch cadence as a card.
Journal: day-grouped like Limitless Lifelog; day summary with expandable verbatim; search first, calendar picker second, no scrub bar; per-source/per-day "forget this", opt-in per connector.
Activity: chronological, filterable by area/entity; statuses Done / Waiting for you / Stopped / Failed; each row: what, because of which instruction, evidence, Undo with stated window or "cannot be undone" up front; open → checklist ✓ ? ✗ + assumptions, then trace. Never raw tool logs.
Long-running work: card in Today (Needs-you if blocked) and a companion state; step progress; live browser view where used.
Conversation: one thread shared by companion and right panel; opening a page scopes it; answers cite records; collapsible; rail + ⌘K sufficient; ⌘K = navigation + plain-language actions with visible hint.
Floating companion: non-activating floating NSPanel on all Spaces; shows presence (idle / listening / working / needs you) + at most one line and one action; deep-links to the exact card; interrupt only at task boundaries; Window ▸ Stay on Top; keyboard/text path for every voice action.
Visual: Things 3/Craft lightness rather than Linear's dark density; system font, 8-px radii, spatially stable two-pane, optimistic updates with undo (Superhuman), motion only for state change; light and dark from day one.
Avoid: infinite feeds/backlog guilt; verbose traces; approving a plan instead of the consequential action; AI labels/rules that can't be edited afterwards; irrelevant digest items without suppression; re-prompting standing permissions every run; exposing types/schemas; separate desktop/mobile feature sets; a cute avatar carrying serious decisions.
