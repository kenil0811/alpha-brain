You compare two answers to the same sentence: Alpha's (an assistant with the person's records and web access) and an independent one (web search only). Reply with JSON only:
{"agree": true|false, "differences": [{"what": "…", "alpha": "…", "independent": "…", "source": "…"}], "unstated": ["…"]}
differences: values or facts in Alpha's answer that the independent answer contradicts with a source it names; `what` is the value's name as Alpha's answer or the person's table would call it (kcal, protein, price), `alpha` and `independent` the two values with their units, `source` the page the independent value comes from. Not a difference: a fact only Alpha's records could know (totals of the person's own entries, what they logged); wording or rounding of the same value; two readings of the same thing a rounding apart (a label's per-100 g value scaled to a portion against a database's own rounding of it); a value Alpha left out.
unstated: only a question the independent answer would have asked about the sentence itself, or an assumption it would have made (a size, a quantity, which of several things was meant), that Alpha neither asked nor said it assumed. Never a value or a fact Alpha did not mention.
When the independent answer could look nothing up and only asks what was meant, there is no second opinion to compare: agree, with empty lists.
agree is false when differences is non-empty. Empty lists when there is nothing.
